# Декодирование слов из ECoG с целями Whisper-base

Чистая публикационная копия ранней серии: MEL40, Whisper-base L1–L6 и заранее
фиксированный ансамбль L3/L4/L5. Сохранена схема: обучение ECoG-регрессора по
речевым признакам → заморозка энкодера → обучение классификатора 27 классов.

Полная инструкция установки и команд — в [README.md](README.md).
Пример конфигурации — `configs/patients.example.json`; собственные пути
запишите в игнорируемый `configs/patients.local.json`. Относительные пути
считаются от каталога JSON. Данные и веса в репозиторий не входят.

Каждый слой и seed получает отдельный каталог. Скрипты не удаляют старые
чекпойнты и отказываются начинать новый запуск поверх непустого каталога.
`train.py --help`, `multiseed.py --help`, `ensemble.py --help` не запускают
обучение. Для проверки плана есть `--dry-run`, для проверки готовых троек —
`ensemble.py --validate-only`.

Исторический график: средний L4 — 73,79%, средняя фиксированная тройка по
пяти seed — 78,07%, лучшие отдельные тройки — 81,35% (362/445). У одиночных
слоёв и ансамблей использовались разные исторические оцениватели метрики.
Подробные числа и оговорки — [HISTORICAL_RESULTS.md](HISTORICAL_RESULTS.md).

Это восстановленная рабочая реализация, а не побайтово подтверждённый снимок
июньского окружения. Исторические пофайловые нормировки и выбор ширины по
метаданным всех разбиений раскрыты в [PROVENANCE.md](PROVENANCE.md).
Правила авторства и статус лицензии исходной работы — [NOTICE.md](NOTICE.md).

Тесты выполняются на синтетических данных и mock-объектах. Новое научное
обучение, инференс на реальных данных и воспроизведение процентов при
подготовке пакета не выполнялись.
